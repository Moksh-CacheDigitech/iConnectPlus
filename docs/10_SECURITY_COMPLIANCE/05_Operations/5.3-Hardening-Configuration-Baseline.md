## 1. Purpose

Define the **hardening baseline** for the **internal Docker Compose server** hosting iConnect Plus: OS, PostgreSQL, reverse proxy, containers, and network exposure on Cache Digitech LAN/VPN.

## 2. Network exposure

| Surface | Production target | Notes |
|---------|-------------------|-------|
| HTTPS (nginx) | LAN + VPN clients only | Example `:8443` |
| PostgreSQL port | Not published to LAN — Docker internal only | Admin via SSH tunnel |
| Redis / RabbitMQ | Internal `erp-net` only | |
| MinIO API | Internal or admin-restricted | |
| RabbitMQ management UI | Disabled or VPN + auth | |
| SSH | IT bastion / restricted IP | Key-based auth |

**Firewall rules document:** **Template / Pending sign-off**

## 3. Operating system (Docker host)

| Control | Baseline |
|---------|----------|
| OS | Linux LTS — **Template / Pending sign-off** version |

| Unused services | Disabled |
| Disk encryption | **Template / Pending sign-off** |
| NTP | See 5.2 |

## 4. Docker & Compose

| Control | Baseline |
|---------|----------|
| Docker version | Pinned major — **Template / Pending sign-off** |
| Root in containers | Non-root user in app images where built |
| Privileged containers | Avoid except AV if required |
| Socket mount | No Docker socket in app containers |
| Secrets | `.env` on host — not committed |
| Image source | Internal registry or built on host from Git tag |
| Resource limits | **Template / Pending sign-off** (CPU/mem) |

## 5. Reverse proxy (nginx)

| Control | Baseline |
|---------|----------|
| TLS | TLS 1.2+; strong cipher suite |
| HSTS | Optional internal — **Template / Pending sign-off** |
| Security headers | `X-Content-Type-Options`, `X-Frame-Options`, etc. |
| Request size | Align with `API_MAX_UPLOAD_REQUEST_BYTES` |
| Server tokens | `server_tokens off` |
| Default server | Drop unknown Host |

Cert files: `docker/nginx/certs/` — permissions `600` for key.

## 6. PostgreSQL

| Control | Baseline |
|---------|----------|
| Version | 16-alpine (inventory 1.5) |
| Superuser use | Migrations and break-glass only |
| App role | Least privilege — DML on app schemas only |
| `listen_addresses` | Internal Docker network |
| Logging | Connection failures, slow queries — **Template / Pending sign-off** |
| Extensions | Only approved via migration |
