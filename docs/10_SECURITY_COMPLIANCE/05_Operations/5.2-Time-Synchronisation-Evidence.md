## 1. Purpose

Demonstrate that systems hosting iConnect Plus maintain **accurate, synchronised time** traceable to **NIC/NPL** or an **internal NTP** hierarchy traceable to them — supporting log correlation, certificate validity, MFA TOTP, and CERT-In incident timelines.

## 2. Scope

| System | Role |
|--------|------|
| Docker application host(s) | Runs all ERP containers |
| Backup / log server (if separate) | Timestamp on archives |
| VPN appliance | Session correlation |
| Admin workstations (ops) | SSH access evidence |

## 3. Policy

| Requirement | Standard |
|-------------|----------|
| Protocol | NTP (chrony or systemd-timesyncd) |
| Stratum | Traceable to NIC/NPL or approved internal source |
| Timezone | UTC on servers; IST for human reports as needed |
| Max drift | **Template / Pending sign-off** (e.g. ≤ 500 ms to source) |

## 5. Evidence collection procedure

Run on each application host (example for chrony):

```bash
timedatectl status
chronyc tracking
chronyc sources -v
```

| Evidence item | Attach to audit pack |
|---------------|----------------------|
| `timedatectl` output | Screenshot or text export |
| `chronyc tracking` | Shows reference ID and offset |
| NTP server allow-list | IT network diagram excerpt |
| Last quarterly review ticket | **Template / Pending sign-off** |

**Collected evidence bundle:** **Template / Pending sign-off**

## 6. Container time

Docker containers inherit host clock. Policy: **do not** run independent NTP inside app containers unless host sync is broken.

| Check | Command |
|-------|---------|
| Container vs host | `docker exec erp-api date -u` vs `date -u` |

## 7. Application impact

| Feature | Sensitivity to clock skew |
|---------|---------------------------|
| JWT expiry | High — skew > few minutes causes auth failures |
| TOTP MFA | High — ±30s window typical |
| Audit `created_at` | Medium — uses UTC from DB/app |
| TLS certificates | High — notBefore/notAfter |

## 8. Remediation

| Condition | Action |
|-----------|--------|
| Skew detected | Fix NTP on host; restart containers if needed |
| NTP unreachable | Failover to secondary NIC/NPL or internal stratum-2 |
| Persistent drift | Replace hardware clock / hypervisor sync review |
