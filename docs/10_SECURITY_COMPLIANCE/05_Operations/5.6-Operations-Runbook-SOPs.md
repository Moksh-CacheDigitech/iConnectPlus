## 4. SOP — Health check

```bash
cd /opt/Cache-ERP   # adjust path
docker compose ps
curl -k -s -o /dev/null -w "%{http_code}" https://127.0.0.1:8443/
docker logs --tail 50 erp-api
docker logs --tail 20 erp-celery-worker
```

| Check | Healthy signal |
|-------|----------------|
| All containers | `Up` (or `healthy` if defined) |
| HTTPS | HTTP 200/302 |
| API | No repeated 5xx in logs |

Platform metrics route (if enabled): internal SLO endpoint — **Template / Pending sign-off**.

## 5. SOP — Rolling restart (no schema change)

| Step | Command / action |
|------|------------------|
| 1 | Notify users if broad impact |
| 2 | `docker compose restart erp-celery-worker` |
| 3 | `docker compose restart erp-api` |
| 4 | `docker compose restart erp-web erp-employee-app` |
| 5 | `docker compose restart erp-nginx` |
| 6 | Run health check (§4) |

Order preserves API before UI; adjust if maintenance window requires full stop.

## 6. SOP — Full stack stop / start

```bash
docker compose down          # caution: does not remove volumes
docker compose up -d
```

**Never** `down -v` in production without DR approval (destroys volumes).

## 7. SOP — Deploy new release

| Step | Action |
|------|--------|
| 1 | Tag / commit recorded in 2.4 change record |
| 2 | Pull Git at release tag on host |
| 3 | Build images: `docker compose build` (or load from internal registry) |
| 4 | Run Alembic: `docker compose run --rm erp-api alembic upgrade head` |
| 5 | Restart api → worker → web → nginx |
| 6 | Smoke test: login, one critical workflow |
| 7 | Monitor logs 30 min |

Rollback: redeploy previous image tag; Alembic downgrade only if approved and tested.

## 8. SOP — Database migration only

| Step | Action |
|------|--------|
| 1 | Backup DB (4.4) |
| 2 | Run `alembic upgrade head` |
| 3 | Verify migration version table |
| 4 | Application smoke test |

## 10. SOP — Secret rotation

See **4.2**. Typical order: generate new secret → update `.env` → restart affected services → invalidate sessions if JWT key changed.

## 11. SOP — Disk space emergency

| Step | Action |
|------|--------|
| 1 | `df -h` on host |
| 2 | Trim old logs per 5.1 retention |
| 3 | Purge unused Docker images `docker system prune` (careful) |
| 4 | Expand volume or archive backups |
| 5 | If PostgreSQL full — stop writes; extend disk |
