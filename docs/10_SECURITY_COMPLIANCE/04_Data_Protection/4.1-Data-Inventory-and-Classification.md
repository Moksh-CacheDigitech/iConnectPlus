## 1. Purpose

Inventory **categories of data** processed by iConnect Plus on **Cache Digitech premises**, assign **classification labels**, and map storage locations on the on-prem stack (PostgreSQL, MinIO, Redis, logs). This supports DPDP accountability, access control design, and encryption scope.

## 2. Classification scheme

Aligned with `apps/api/src/modules/platform/data_classification.py`:

| Level | Code | Description | Handling |
|-------|------|-------------|----------|
| Public | `public` | Non-sensitive; may appear in marketing or open docs | Standard access controls |
| Internal | `internal` | Business operational; not for external disclosure | RBAC; LAN/VPN only |
| Confidential | `confidential` | PII, customer/vendor, HR, audit metadata | RBAC + encryption where inventoried; need-to-know |
| Restricted | `restricted` | Credentials, tokens, payroll, bank, high-impact finance | Strong RBAC, Fernet fields, no plaintext logging |

## 3. Data stores (on-premises)

| Store | Technology | Volume / path (typical) | Primary contents | Location |
|-------|------------|-------------------------|------------------|----------|
| OLTP | PostgreSQL 16 (`erp-postgres`) | `erp_pgdata` | All tenant business entities | India — premises |
| Objects | MinIO (`erp-minio`) | `erp_minio_data` | Attachments, exports, document binaries | India — premises |
| Cache / sessions | Redis (`erp-redis`) | `erp_redis_data` | Permission cache, Celery results (non-authoritative) | India — premises |
| Messages | RabbitMQ | `erp_rabbitmq_data` | Async job envelopes | India — premises |
| Upload scratch | Docker volumes | `erp_crm_uploads`, `erp_asset_storage` | Transient upload paths | India — premises |
| Application logs | Host / container logs | **Template / Pending sign-off** path | Security & ops events | India — premises (≥180d target) |

No **primary** business OLTP or object store is hosted on public cloud in this deployment model.

## 7. Data flows (summary)

| Flow | Path | Classification impact |
|------|------|------------------------|
| User browser → app | LAN or VPN → TLS (nginx) → web/API | All classes in transit protected by TLS |
| API → PostgreSQL | Docker network `erp-net` | At-rest: DB volume encryption **Template / Pending sign-off** (OS/disk) |
| API → MinIO | S3-compatible internal endpoint | Bucket policy + credentials in `.env` |
| Optional email/SMS | SMTP/Brevo, FCM | Message content may include confidential data — processor agreements **Template / Pending sign-off** |
| Backups | pg_dump / volume snapshot → on-prem target | Same classification as source — see 4.4 |
