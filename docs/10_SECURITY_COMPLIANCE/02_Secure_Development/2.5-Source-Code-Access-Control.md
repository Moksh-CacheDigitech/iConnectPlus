## 1. Purpose

Document **access controls for iConnect Plus source code** hosted on GitHub while **production runtime and data** remain on Cache Digitech premises.

## 2. Repository inventory

| Remote name | URL | Role |
|-------------|-----|------|
| `origin` | `https://github.com/ronanop/enterprise-erp.git` | Primary — fetch and default push |
| `iconnectplus` | `https://github.com/Moksh-CacheDigitech/iConnectPlus.git` | Always-synced mirror (code/refs) |
| `iconnectplus-erp` | `https://github.com/moksh-sharma/iConnectPlus-ERP.git` | Always-synced mirror (code/refs) |
| `gitlab` | Internal GitLab host | Mirror on explicit request only |

Mirrors sync **code and refs only** — not GitHub collaborators or team settings.

## 5. Separation: source vs runtime

| Asset | Location | Access path |
|-------|----------|-------------|
| Source code | GitHub | Internet + GitHub auth |
| Production DB | On-prem PostgreSQL | LAN/VPN only |
| Production secrets | Host `.env` | SSH / secrets manager — **Template / Pending sign-off** |
| CI artifacts (if any) | **Template / Pending sign-off** | Restricted |

Compromise of GitHub **must not** directly expose production DB without separate credential theft on premises.
