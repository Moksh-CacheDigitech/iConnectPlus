## 1. Purpose

Track **SAST**, **DAST**, **dependency scanning**, and **VAPT** activities and remediations for iConnect Plus targeting the **on-premises** deployment (internal URL, VPN context).

## 2. Scope of testing

| Layer | In scope | Notes |
|-------|----------|-------|
| FastAPI `/api/v1` | Yes | Cookie auth, RBAC, rate limits |
| Next.js admin | Yes | XSS, CSRF protections via SameSite cookies |
| ESS app | Yes | Login CAPTCHA optional |
| Infrastructure | Partial | IT owns network/VPN; app team owns containers |
| MinIO / Postgres | Config review | Not internet-exposed |

Historical code references to VAPT (e.g. ClamAV 7.1.25, session binding) exist in `apps/api` — formal reports should be attached when available.
