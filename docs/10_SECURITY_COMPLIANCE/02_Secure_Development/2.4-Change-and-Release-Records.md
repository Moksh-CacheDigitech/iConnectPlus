## 1. Purpose

Provide a **template and register** for tracking application and infrastructure changes deployed to **on-premises** iConnect Plus hosts.

## 2. Release process (on-premises)

| Step | Activity | Owner |
|------|----------|-------|
| 1 | Merge to `main` on GitHub `origin` | Engineering |
| 2 | Build Docker images on deploy host or CI artifact | Platform |
| 3 | Run Alembic migrations (`RUN_MIGRATIONS=true` on API container) | Platform |
| 4 | Rolling restart via `docker compose` | Platform + IT |
| 5 | Smoke test (health, login, critical module) | QA / Platform |
| 6 | Update change record below | Release manager |

Mirrors (`iconnectplus`, `iconnectplus-erp`) sync code refs per org policy — **runtime remains on-prem**.
