## 1. Purpose

Define the **periodic access review process** for iConnect Plus accounts, roles, and related **VPN** access on Cache Digitech infrastructure. This register uses **templates** until official reviews are completed and signed.

## 2. Scope of review

| Access type | System | Review owner |
|-------------|--------|--------------|
| Application login | iConnect Plus `sec_user` | Tenant admin + HR |
| Application roles / permissions | RBAC assignments | Tenant admin |
| Privileged roles | `SUPER_ADMIN`, `TENANT_ADMIN`, module admins | Platform + security |
| VPN remote access | IT VPN directory | IT Infrastructure |
| GitHub source access | GitHub org | Engineering manager |
| Server / Docker admin | SSH, host groups | IT Infrastructure |

## 3. Review cadence (template policy)

| Review | Frequency | Next due |
|--------|-----------|----------|
| Standard user roles | Quarterly | **Template / Pending sign-off** |
| Privileged / admin roles | Monthly | **Template / Pending sign-off** |
| VPN users | Quarterly | **Template / Pending sign-off** |
| Terminated employees | Within 24h of exit | HR trigger |

## 4. Review procedure

| Step | Action | Evidence |
|------|--------|----------|
| 1 | Export user list with roles per tenant | Admin UI / SQL read-only |
| 2 | Managers certify direct reports | Email or ITSM ticket |
| 3 | Remove unjustified roles | Change record §2.4 |
| 4 | Disable inactive accounts (>90d) | **Template / Pending sign-off** policy |
| 5 | Cross-check VPN list vs active employees | IT export |
| 6 | Document completion in §5 register | Sign-off |
