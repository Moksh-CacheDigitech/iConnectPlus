### 2. What data we process

We process personal data needed to run ERP functions, including:

- Identity and contact details (name, email, phone)  
- Employment and HR records  
- Payroll and tax identifiers where applicable  
- Usage and security logs (IP address, login times)  
- Files you upload that may contain personal information  

Sensitive fields (e.g. bank account, PAN, Aadhaar where collected) receive **additional encryption** in the application.

### 3. Why we process data

| Purpose | Examples |
|---------|----------|
| Employment and HR | Payroll, attendance, lifecycle |
| Business operations | Finance, procurement, customer/vendor management |
| Security | Authentication, fraud prevention, audit |
| Communications | Notifications you receive from the system |

Lawful basis details for your organisation are recorded in **4.5 Personal Data Processing Record**.

### 4. Where data is stored

Primary storage is **on-premises** at Cache Digitech (PostgreSQL database and MinIO object storage). Data is **not** stored on public cloud databases as the primary production model for this deployment.

Remote access is only through **Cache Digitech VPN** plus internal network controls.

### 5. Who can access data

- Authorised users per **role-based access control**  
- IT and platform teams for operations, backups, and security (under policy)  
- Optional subprocessors (e.g. email delivery, SSO) only if enabled — see **4.5**

### 6. Retention

We retain data according to schedules in **4.3**, including approximately:

- Operational records: **3 years** (default class)  
- Audit records: **10 years**  
- Notifications: **1 year**  
- Security logs: **at least 180 days** on-premises

- Access to your personal data

### 8. Security measures

We use industry practices including TLS, password hashing (bcrypt), optional MFA, access controls, encryption of designated fields, and account lockout after failed logins. Details: security pack sections **4.2**, **5.3**, **3.1**.

### 9. Incidents
