## 1. Purpose

Explain how **artificial intelligence (AI)** and **automated assistance** may be used in iConnect Plus so users can make informed decisions. This notice supplements **6.3 Privacy Notice & Terms of Use**.

## 2. Scope of AI features

| Feature area | Description | Availability |
|--------------|-------------|--------------|
| AI Assistant | Conversational help, summaries, drafting suggestions | **Template / Pending sign-off** per tenant/module |
| Virtual E.A. | Task-oriented executive assistant flows | **Template / Pending sign-off** |
| Embedded suggestions | Inline text completion or classification | **Template / Pending sign-off** |

If a feature is not enabled for your tenant, this notice applies only when that feature is turned on.

## 3. How AI works (high level)

```text
User prompt (LAN/VPN) → iConnect Plus API → AI orchestration layer → Model provider / local model
                              ↓
                    RBAC + tenant context applied before tools/data access
```

| Aspect | Policy |
|--------|--------|
| Authentication | Same as core app — JWT HttpOnly cookies, RBAC |
| Network | Access only via **LAN or Cache Digitech VPN** to on-prem app |
| Data sent to models | Prompts may include text you provide and **permitted** context fields |
| Automated decisions | **No fully automated legal/hr/finance decisions** without human review unless explicitly configured — **Template / Pending sign-off** |

## 4. Model & infrastructure disclosure

| Item | On-premises deployment (v2.0) |

| Primary ERP data | Stays in on-prem PostgreSQL / MinIO |

## 5. Personal and confidential data

- Do **not** paste **restricted** data (full PAN, Aadhaar, passwords, unrestricted salary lists) into AI prompts unless policy explicitly allows.  
- The system applies **data classification** (`public` / `internal` / `confidential` / `restricted`) — AI tools must respect RBAC when retrieving context (**4.1**).  
- Optional redaction layer: **Template / Pending sign-off**

## 6. Accuracy and limitations

AI outputs may be **incorrect, incomplete, or outdated**. You must:

- Verify facts before business, legal, or HR actions  
- Treat AI output as **assistive**, not authoritative  
- Escalate to human experts for regulated decisions
