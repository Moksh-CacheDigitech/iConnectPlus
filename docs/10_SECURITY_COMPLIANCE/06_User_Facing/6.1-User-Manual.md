## 1. About iConnect Plus

**iConnect Plus** is Cache Digitech’s internal enterprise resource planning application for HR, finance, operations, and related business modules. It runs on **company servers inside Cache Digitech premises** — not as a public internet SaaS product for this deployment.

## 2. How to access the application

| Location | How to connect |
|----------|----------------|
| **Office (corporate LAN)** | Open the internal URL provided by IT (example: `https://172.16.200.30:8443`) in a supported browser |
| **Remote (home / travel)** | Connect to **Cache Digitech VPN first**, then open the same internal URL |

Without VPN, remote access is **not** available. Do not attempt to expose the application on the public internet.

**Supported browsers:** Current Chrome, Edge, or Firefox — **Template / Pending sign-off** for minimum versions.

## 3. Signing in

1. Navigate to the admin or ESS URL after LAN/VPN connection.  
2. Enter your **work email** and **password** provided by your administrator.  
3. If your account has **multi-factor authentication (MFA)** enabled, enter the **6-digit code** from your authenticator app when prompted.

### 3.1 Security features you should know

| Feature | What it means for you |
|---------|------------------------|
| **Secure password storage** | Passwords are stored using strong hashing — IT cannot read your password |
| **Optional MFA (TOTP)** | Extra code from phone app for higher-risk accounts |
| **Session cookies** | Stay signed in securely; sign out on shared PCs |
| **Account lockout** | After **5** failed login attempts, account locks for **15 minutes** — contact admin if needed |
| **Role-based access** | You only see menus and data your role allows |

## 4. Navigation

- Use the **left sidebar** to move between modules (HR, Finance, etc.) enabled for your tenant.  
- Use **search** and **filters** on list pages where available.  
- **Help** links inside modules — **Template / Pending sign-off** per module rollout.

## 5. Common tasks

| Task | Where |

| Submit leave / attendance | ESS or HR module (per configuration) |
| View payslips | Payroll / ESS — **Template / Pending sign-off** |

## 6. Data handling expectations

- Do not share your password or MFA device.  
- Do not copy **confidential** or **restricted** data to personal email or cloud drives unless policy allows.  
- Report suspicious login or data issues to IT immediately.

Classification levels used by the platform: **public**, **internal**, **confidential**, **restricted** — see administrator guidance in **6.2**.

## 7. Sign out

Use **Sign out** from the user menu, especially on shared computers. Closing the browser may end the session depending on settings.
