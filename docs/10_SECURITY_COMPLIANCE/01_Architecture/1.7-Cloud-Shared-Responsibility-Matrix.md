## 1. Purpose

Clarify **who is responsible** for security and operations when iConnect Plus runs on **Cache Digitech-owned premises infrastructure**, accessed via **corporate LAN** and **VPN**. This matrix **replaces** AWS-style cloud shared-responsibility as the primary framing for this compliance pack.

Filename retained for document numbering continuity: `1.7-Cloud-Shared-Responsibility-Matrix.md`.

## 2. Parties

| Party | Role |
|-------|------|
| **Cache Digitech IT / Infrastructure** | Physical server, LAN, firewall, VPN, OS patching, backups, TLS certs at edge |
| **Application / Platform team** | Docker Compose, application code, schema migrations, RBAC catalog, secrets injection |
| **VPN provider / vendor** (if not wholly in-house) | VPN appliance availability per contract |
| **End users** | Credential hygiene, MFA devices, acceptable use |
| **Third-party SaaS (optional)** | GitHub (source), Microsoft Entra (SSO), SMTP — per vendor terms |

## 4. Data protection split
